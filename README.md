# Stack

Stack is a mobile-first web app for creating and sharing short, useful lists.

## Party Mode v1 handoff

- [Functional spec](docs/stack-spec.md) is the source of truth for the next version. Follow its agreed decisions and proposed defaults, and keep the remaining open decisions visible.
- [Build handoff](docs/stack-spec.md#build-handoff) covers responsive layouts, design tokens, reusable components, assets, and a worked example.
- [Party Mode design references](project/party-mode/README.md) include the mobile, editor, and desktop prototypes, screenshots, and the app icon pack.
- [Product tenets](docs/product-tenets.md) and the [focused flow guides](docs/user-flows/) support the functional spec.
- [Current web app](web/README.md) documents the implementation and how to run it locally.

The earlier export in `project/`, the transcripts in `chats/`, and the existing `apply-design` workflow describe the previous release. For Party Mode work, follow the new spec even where those materials prescribe different behavior. The prototypes are visual references. Implement the flows in the Next.js app with Supabase-backed data.
