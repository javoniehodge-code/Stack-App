Create a Stack — mobile flow
Every phone below is live: type, paste a link, reorder, publish. Title and description are skippable. From step 3 on you're editing the Stack as visitors will see it. Drafts save automatically, and Exit keeps your work.
1aStep 1 · Title
A blank screen with one line to type on. Skip turns into Next once you've typed something. A title is only asked for again at publish.
1bStep 2 · Description
Same pattern. The description stays optional, even at publish.
1cStep 3 · Build, empty
Title and description were skipped, so they show as dashed placeholders you can tap to edit. The first line is ready to type into. Enter starts the next line.
1dStep 3 · Build, in progress
This reads like the published Stack. Lines 02 and 05 are text only; 01, 03 and 04 have links with their fetched title and favicon. There's one subsection. Tap any line to edit it.
1eStep 3 · Editing a line
Edit controls appear only on the selected line: move, delete, link, and an "Added by you" label. A pasted URL fetches its title and favicon in place.
1fStep 4 · Review, arrange
Reorder lines and subsections; changes show immediately.
1gStep 4 · Preview
The exact visitor view with every editing control hidden. Only Exit preview and Publish remain.
1hPublish · title was skipped
The only thing publish requires: a title and at least one line with text. Description, subsections and links are never required.
1iAfter Exit · Drafts
Exit keeps the draft and returns to Profile › Drafts. Reopening lands on Build with content, order and theme intact.
